**Change C — Click handler (`<script>` inside the page):**

Add a bundled (NOT `is:inline`) `<script>` tag inside the `<body>`, after the closing `</main>` and before the closing `</body>`, that wires the button to `window.print()` per D-01:

```astro

  const btn = document.getElementById('download-pdf');
  if (btn) {
    btn.addEventListener('click', () => {

    });

</script>
```

Rationale: Astro bundles plain `<script>` tags. The page is standalone and not part of the View Transitions pipeline (per D-04 — `ViewTransitions` is not imported), so a single `astro:after-swap` re-init is unnecessary. Do NOT use `is:inline`. Inline scripts are not deduped and we want Astro's standard module bundling for this single one-liner.
